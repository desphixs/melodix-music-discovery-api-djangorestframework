# Build Melodix: Music Discovery API

### Project Description

You are going to build Melodix, a beautiful back-end API for a collaborative music discovery app. You will start by setting up a database catalog to store individual songs and genres using Django REST Framework. Once your catalog is ready, you will build the core feature: playlists that link multiple songs and genres together. You will write custom serializer logic to let users add multiple songs to a playlist in a single request, build a manual search filter so users can find playlists by genre or song title, and write custom code to page through long lists of songs inside a playlist. Finally, you will add a comment section for each playlist so users can talk about their favorite tracks. You will build all of this using raw APIView classes so you understand every single detail of how class-based views process requests under the hood.

## Tech Stack

- Django
- Django REST Framework
